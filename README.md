# Free Game SFX & Pixel Asset Library

A free, static, searchable catalog of game sound effect, ambience, music and 16x16 pixel art packs by [yetiancai](https://yetiancai.itch.io/).

Live site: https://yetiancai12.github.io/free-game-sfx/

- No shop, ads, analytics or cookies. Packs are downloaded and paid for on itch.io, Gumroad, Ko-fi and Fab.
- Pack data (counts, formats, license wording) comes from the store listings.
- Search runs in the browser over `search.json`.
