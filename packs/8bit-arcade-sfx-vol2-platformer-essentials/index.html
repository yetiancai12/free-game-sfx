What is in it

The platformer layer for your 8-bit game. 8-Bit Arcade SFX Vol.2 is 176 chiptune sounds made for 2D platformers: jumps (single, double, light, heavy), four landing weights, wall jump and wall slide, springs and bounce pads, dash and roll, coins, coin cascades and gems, power-ups, star and 1-up, question blocks and brick breaks, stomps and shell hits, spikes, lava, pits and poison, pipes, doors, checkpoints and teleports, and short level-clear, death and retry jingles. 46 sound types, 3–6 takes each.

Built around a platformer's moment-to-moment loop, not a random folder of blips

  • Move: plat_jump_single / plat_jump_double / plat_jump_light / plat_jump_heavy, then plat_land_soft → plat_land_hard → plat_land_heavy by fall speed (PlatSfx.land(fall_speed) picks one), plus plat_wall_jump, plat_wall_slide, plat_spring, plat_bounce_pad, plat_dash_start / plat_dash_air / plat_dash_end and plat_roll.
  • Collect: plat_coin (6 takes so a coin line does not sound copy-pasted), plat_coin_multi cascades, plat_coin_secret, plat_gem, plat_powerup, plat_star, plat_1up and plat_power_end.
  • Bump and stomp: plat_block_bump, plat_block_question, plat_block_break, plat_block_switch, plat_stomp, plat_stomp_multi, plat_shell_hit and plat_enemy_pop.
  • Danger and flow: plat_spike, plat_lava, plat_fall_pit, plat_poison; plat_pipe_enter / plat_pipe_exit, plat_door, plat_checkpoint, plat_teleport; and jingles plat_clear, plat_world_clear, plat_death, plat_retry, plat_secret.

Made for game feel

  • Classic 8-bit voice: square, pulse and triangle waves plus noise, with stepped envelopes and pitch sweeps, so it sits next to NES/Game Boy style art
  • Snappy: every sound starts within 5 ms of the file start (no silent lead-in) and ends with a short fade, so there are no clicks when it is cut off
  • Mixed by job: movement and warp sounds at -18 LUFS, coins, power-ups, blocks, stomps and jingles at -16 LUFS, hazards at -14 to -15 LUFS so damage cuts through. True peak ≤ -1 dBTP, 0 clipped samples
  • 48 kHz / 24-bit mono WAV + OGG Vorbis (48 kHz), same file names in both; every file measured (length, loudness, peak in MANIFEST.csv)

Godot 4 + Unity drop-in: copy ogg/ to res://plat_sfx/ and add engine/plat_sfx.gd as an Autoload named PlatSfx, or copy it to Assets/Resources/PlatSfx/ and add the PlatSfx component to one GameObject in Unity. Then PlatSfx.play("plat_coin") / PlatSfx.Play("plat_coin") plays a random take (never the same take twice in a row); plus jump("double"), land(fall_speed) (0..1 picks soft / hard / heavy), coin(streak) (5+ plays the coin cascade) and play_at / PlayAt for positional sounds. The Godot helper was tested headless in Godot 4.7.2 (every file loads, every helper call runs); the Unity script builds with 0 errors against a UnityEngine stub (not yet run inside the Unity editor). File names are plain lowercase snake_case with a plat_ prefix, so they never collide with Vol.1, and GameMaker, Defold, Construct, Phaser or Unreal work too.

Vol.2 of my 8-Bit Arcade series: 8-Bit Arcade SFX 192 (Vol.1) covers UI, pickups, movement, combat and jingles in general; Vol.2 goes deep on platformer moves, level objects and level feedback.
