What is in it

Little monsters need little voices. Squeaklings is a sound pack of cute creature and critter voices: a burbling slime, a peeping chick, a squeaky mouse, a cooing fluffball spirit, a croaky frog, a chirpy bat, a clicky beetle and a clacky baby rock golem. Each one can idle, be happy, get alert, attack, get hurt and faint, with 5 variations of every sound, plus spawn, befriend, evolve, munch, pet and sleep events. 270 sounds.

Built as a creature × action grid. Every file is named <creature>_<action>_01..05. Each of the 8 creatures has its own voice and the same 6 actions: idle (ambient chirp / burble while it wanders), happy, alert (it spotted you), attack, hurt and faint. So your monster data can pick the sound: CritterSfx.play(monster.kind, "hurt"). Plus 6 shared critter events every creature can use: spawn, befriend / tame, evolve, munch, pet and sleep.

  • Slime: squishy blub voice + bubbles and squelch
  • Chick (tiny bird): tiny bird chirps
  • Mouse: high squeaks
  • Puff (fluffball / spirit): soft breathy coos (fluffball / spirit)
  • Frog: croaky ribbit voice
  • Bat: little eek + wing flutter
  • Beetle (bug): clicky bug voice + wing buzz
  • Pebble (baby golem): low rumbly baby golem + stone clacks

Made for game feel

  • Cute, not scary: bright, small-creature voices for pets, monster collectors, cozy RPGs, platformers and kids' games — no growls, gore or horror screams
  • Each creature has its own character: slime burbles, chick peeps, mouse squeaks, puff coos, frog croaks, bat chirps and wing flutters, beetle clicks and buzzes, pebble clacks and hums
  • Loudness by action: idle, munch, pet and sleep -20 LUFS (background), happy / alert / attack / hurt / faint / spawn -18 LUFS, befriend and evolve -16 LUFS (reward moments). The 5 variations of a sound match within 0.1 dB
  • Snappy: every sound starts within 5 ms of the file start (no silent lead-in) and ends with a clean tail
  • True peak ≤ -1 dBTP, 0 clipped samples; 48 kHz / 24-bit stereo WAV + OGG Vorbis, same file names in both; QA report with the measurement of every file

Godot 4 + Unity drop-in: copy ogg/ to res://squeaklings/ and add critter_sfx.gd as an Autoload named CritterSfx, or copy it to Assets/Resources/Squeaklings/ and add the CritterSfx component in Unity. Then CritterSfx.play("slime", "attack") / CritterSfx.Play("slime", "attack") plays a random variant (never the same one twice in a row) with a small pitch variation; play_at / PlayAt for positional sounds.

One voice, many sizes: pass a size, e.g. CritterSfx.play("slime", "attack", 2.5) for a king slime (lower, slower) or 0.5 for a baby one (higher, quicker). The helper turns size into playback pitch (clamped 0.6–1.6), so one creature voice covers a whole family of monsters. The Godot helper was tested in Godot 4.3 (every file loads). File names are plain lowercase snake_case, so GameMaker, Unreal, Defold, RPG Maker, Construct or Phaser work too.
