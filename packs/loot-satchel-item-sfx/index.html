What is in it

Every item in your bag should sound like what it is. Loot Satchel is a sound pack for RPG, survival, crafting and adventure games: coins that clink and bounce, gems that ping, potion bottles that slosh and get drunk, blades that ring and slide into a sheath, plate armor and chainmail, cloth and leather, wooden tools, paper, scrolls and books, food and herbs, backpacks and treasure chests, plus craft success, item break and "inventory full". 160 sounds, 5 variations of each.

Built as a material × action grid. Every file is named <material>_<action>_01..05: coin, gem, potion, blade, armor, cloth, wood, paper and food each have a pick-up sound, most have a drop sound, and each material gets its own equip / use / open sound (coin pouch, gem socket, potion drink, blade sheath, chainmail, leather, scroll unroll, book close, eat, herb pick). So your item data can pick the sound: ItemSfx.play(item.material, "pickup"). No more one generic "item" blip for a sword, a potion and a scroll.

Made for game feel

  • Layered, not single blips: drops are the object's own ring + a wooden-floor thud + smaller bounces; pick-ups add the handling rustle; potions add liquid slosh and gulps
  • Loudness by action: soft handling (cloth, paper, food, bags) -20 LUFS, pick-ups / drops / equips -18 LUFS, craft success -16 LUFS. The 5 variations of a sound match within 0.1 dB
  • Snappy: every sound starts within 5 ms of the file start (no silent lead-in) and ends with a clean tail
  • Reward sounds are brighter: gem pick-up, gem socket, potion heal and craft success add bright chime notes from one pentatonic scale, so they fit each other
  • True peak ≤ -1 dBTP, 0 clipped samples; 48 kHz / 24-bit stereo WAV + OGG Vorbis, same file names in both; QA report with the measurement of every file

Godot 4 + Unity drop-in: copy ogg/ to res://loot_satchel/ and add item_sfx.gd as an Autoload named ItemSfx, or copy it to Assets/Resources/LootSatchel/ and add the ItemSfx component in Unity. Then ItemSfx.play("potion", "drink") / ItemSfx.Play("potion", "drink") plays a random variant (never the same one twice in a row) with a small pitch variation; play_at / PlayAt for positional sounds. The Godot helper was tested in Godot 4.3 (every file loads). File names are plain lowercase snake_case, so GameMaker, Unreal, Defold, RPG Maker, Construct or Phaser work too.
