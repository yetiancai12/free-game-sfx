What is in it

Walk through the door and the storm follows you. Doorway Ambience gives you 10 ambience scenes, each in three places to stand: outside in it, indoors behind walls and glass, and distant across open ground. The three loops of a scene share one timeline, so the same thunder roll, wave or gust happens at the same moment in all three. Start them together and crossfade when the player goes inside. Nothing jumps.

Built for games

  • Synced positions: all three loops of a scene are mixed from one render, same length to the sample (60.000 s), events line up
  • Seamless loops: built sample-periodically (the end flows into the start with no crossfade bump), seam checked on every file, WAV loop point (smpl chunk) included
  • Same loudness in every position (-20 LUFS loops, -18 LUFS accents, -16 LUFS thunder clap), so a crossfade doesn't dip or jump; true peak ≤ -1 dBTP, no clipping
  • Indoors is more than a filter: the building adds its own layer: roof drumming, window rattles, whistles, chimney moan, quiet room tone
  • Easy on the ears for long play: under 10% of the energy above 8 kHz in every file
  • 48 kHz / 24-bit stereo WAV for editing + OGG Vorbis for your engine, same file names in both; every file measured, QA report in the pack

Godot / Unity / FMOD Godot 4: Import dock → Loop ON, start three AudioStreamPlayers in the same frame and tween volume_db. Unity: tick Loop and start the three AudioSources with PlayScheduled at the same dspTime. FMOD / Wwise: put the three on one blend container driven by an "inside" parameter. The README has the details.
