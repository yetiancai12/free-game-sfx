What is in it

Every party needs a healer, and every healer needs to sound good. Mendsong is 216 holy, healing and support spell sounds for RPGs, roguelikes, action and strategy games: heals from a tiny regen tick to a full restore, an 8-step heal-chain ladder, revive and resurrection, blessings that apply and expire, a divine shield that forms, absorbs and breaks, cleanse, dispel and resist, holy attacks (smite, holy bolt, judgement, nova, undead sizzle), casting charge-ups and fizzles, and 12 seamless sustain loops. 5 variations of most sounds.

Built as a healer's sound kit, not a random folder of sparkles

  • Heals that scale: heal_tick (-24 LUFS) → heal_small (-20) → heal_medium (-18) → heal_large / heal_full (-16). A bigger heal is bigger and louder, no mixer work. MendSfx.heal(amount, max_hp) picks the right one.
  • Heal-chain ladder: heal_chain_1 … heal_chain_8 climb D major pentatonic. Use it for bounce heals that jump from ally to ally, combo counters, or several pickups in a row: MendSfx.chain(hop).
  • Everything in one key: chimes, choirs and loops are tuned to D major, so a heal over a sanctuary aura over a blessing never clashes.
  • Buffs in pairs: bless, ward (defense up), haste, might (attack up) and regen each have an _apply and a quieter _expire, so players hear when a buff wears off.
  • 12 seamless loops (12 s, sample-exact, WAV loop points) for sanctuary auras, channelled heals, a held divine shield and consecrated ground; loop_start / loop_stop fade them in and out.

Made for game feel

  • Warm and bright, not harsh: bell chimes, soft "ah"/"oo" choir pads and glitter, with the energy kept below 8 kHz so they sit nicely on laptop and phone speakers
  • Snappy: every one-shot starts within 5 ms of the file start (no silent lead-in) and ends with a clean tail; the variations of a sound match within 0.1 dB
  • True peak ≤ -1 dBTP, 0 clipped samples; 48 kHz / 24-bit stereo WAV + OGG Vorbis, same file names in both; QA report with the measurement of every file

Godot 4 + Unity drop-in: copy ogg/ to res://mendsong/ and add mend_sfx.gd as an Autoload named MendSfx, or copy it to Assets/Resources/Mendsong/ and add the MendSfx component in Unity. Then MendSfx.play("smite") / MendSfx.Play("smite") plays a random variant (never the same one twice in a row); plus heal, chain, buff, loop_start / loop_stop and play_at / PlayAt for positional sounds. The Godot helper was tested headless in Godot 4.3 (every file loads). File names are plain lowercase snake_case, so GameMaker, Unreal, Defold, RPG Maker, Construct or Phaser work too.
