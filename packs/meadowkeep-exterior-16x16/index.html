What is in it

635 tiles · 600 static + 35 animated (140 frames) · 10 autotile sets · 11 OGG ambient loops · Godot 4 + Tiled

Build a quiet meadow town in an afternoon. Meadowkeep Exterior is a 16x16 top-down outdoor tileset that matches Meadowkeep Interior's 48-colour palette - same plaster, wood and window colours indoors and out.

Three things this pack is built around 1. Ambient sound included - 11 seamless OGG loops (meadow, forest, wind, river, ocean, rain, thunder, night crickets, town murmur, campfire). 2..aseprite sources for every animation - open them in Aseprite or LibreSprite; each file was pixel-roundtrip verified. 3. Roof autotile - terra-cotta, thatch and slate roofs are full 47-tile blob sets. Paint any roof shape; fences and low stone walls use 16-mask neighbourhoods too.

What's inside (635 tiles: 600 static + 35 animated, 140 frames) - Terrain autotile: dirt path, stone path, tall grass, sand, stone retaining wall, water shore, natural cliff (10 blob sets total including roofs) - Ground fills: grass, tall grass, dirt, sand - House exteriors: plaster / brick / wood walls, 3 roof styles (autotile), ridge, gable, chimney + smoke - Doors and windows (day/night, open/closed, flower box) - Wood fence (16 masks) + gate; low stone wall (16 masks) - Trees (broadleaf + pine, wind animation), sapling, bush, stump - Town props: well, barrel, crate, bench, lamp post, signpost, flower box, haystack, firewood, mailbox, bucket, grain sack, potted plant, rocks, mushrooms, pumpkin patch, vegetable bed, market stall, cart, notice board, laundry line, stepping stones - Animated: water, shore, chimney smoke, teal flag, windmill, wind grass, trees, campfire, hanging lantern

Animation built in - Tiled tile animations and a Godot 4 TileSet animation setup are included. Autotile built in - Tiled wangsets and a Godot 4 terrain set (match corners and sides). Sound effects included - 11 OGG ambient loops from our own Ambient Loops pack.

Tested before packaging - Godot 4.3 and 4.7.2 headless: TileSet build, set_cells_terrain_connect autotile, animation frame counts, audio load + play. Logs are in the pack. Tiled.tsx /.tmx are valid XML with wangsets; wangset logic was checked in Python (Tiled CLI was not on the build machine).

Files: tilesheet PNG (1x + 4x), every tile as a single PNG, tile index (TXT + JSON), multi-tile object list (JSON), Tiled.tsx + example.tmx, Godot 4 project + tests, palette (.hex/.gpl/.png), OGG sounds, Aseprite/LibreSprite.aseprite sources, preview GIFs. Engines: Godot 4.3+, Tiled, Aseprite/LibreSprite; the PNG sheet works in Unity, GameMaker, RPG Maker or any engine that reads a 16px grid.

v1.1 (2026-11-05)

Free update. Existing projects keep working: every v1.0 tile id is unchanged.

Added: Natural cliff terrain (cliff): 47-mask blob autotile + 4 fill variants. Irregular rock strata, diagonal cracks, and slope bevels. Visually distinct from the existing stone retaining wall (large flat slabs). Uses the Meadowkeep-48 palette only. New tile ids start at 716.

Changed: path_stone collision removed in the Godot TileSet. The stone path is walkable. stone_retaining_wall and the new cliff keep collision.

Unchanged: Tile ids 0..715 and their sheet pixels match v1.0. Terrain index order for the original 9 terrains is unchanged (cliff is appended). Audio, animations, roofs, fences, props: same as v1.0.

Counts: Static tiles 600 (was 549; +51). Animated tiles 35. Title total 635. Blob sets: 10 (path_dirt, path_stone, grass_tall, sand, stone_retaining_wall, water, roof_terra, roof_thatch, roof_slate, cliff).
