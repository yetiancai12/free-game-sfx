What is in it

One bundle with four Meadowkeep 16x16 top-down pixel art packs that share a palette and outline style:

  • Pixel Font 5x7: 191 characters, Regular + Bold, TTF / OTF / WOFF
  • UI Icons: 16x16 RPG inventory and HUD icons with 2x / 4x versions, spritesheets and an index (see the UI Icons pack page for the current icon count)
  • Tileset: 391 tiles, 6 blob autotile sets, Tiled .tsx + example map
  • Heroes & Monsters: 12 animated sprites, 32 frames each, 4-direction walk
