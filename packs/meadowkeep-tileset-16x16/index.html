What is in it

A cozy, consistent 16x16 top-down tileset for RPGs, farming and adventure games.

What's inside

  • 6 complete 47-tile blob autotile sets: dirt, sand, water, stone path, tall grass, water-on-sand
  • Grass, dirt, sand, water, path fills; brick/stone walls; dungeon floors; stairs; grate; door
  • Trees, bushes, rocks, flowers, fences & gates, bridges, chests, props
  • PNG at 1x / 2x / 4x; tile index (txt + json); Tiled.tsx + example.tmx

Autotile built in — blob sets ready for Tiled wangsets / engine autotile. Previews include fence auto-connect and stone-path paint demos, plus a Godot 4 TileMapLayer runtime capture.

Goes with: Meadowkeep Heroes & Monsters, UI Icons, Pixel Font, Interior (same palette family).

Free version (YetiancaiTileset16-FREE-GrassKit.zip): 88 tiles, all static — 4 grass fills, a full 47-tile tall-grass blob autotile (+2 fills), bushes, flowers, grass tufts, rocks, pebbles, a sapling and 3 oak trees (2x2). PNG at 1x / 2x / 4x + tile index. The full pack has 391 tiles, 6 blob autotile sets, walls, dungeon, fences, chests, props and Tiled.tsx + example map.
