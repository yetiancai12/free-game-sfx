What is in it

6 winter scenes, each with 3 layered loops (bed / snow / full mix) — 18 seamless loops for snowy paths, cozy cabins, frozen creeks and winter towns. About 1 minute each (~18 min total), 48 kHz / 24-bit WAV + OGG, loudness-matched.

Six places, three layers each — every place ships three layers you can stack or swap in-engine

  • scene_bed — the place itself without the weather layer
  • snow_layer — soft snowfall / frost hush alone, to fade up when the storm grows or the player steps outside
  • full_mix — bed + snow already combined, for when you only want one track

What's inside: 18 loops, each as WAV + OGG (36 audio files) + README, LICENSE, MANIFEST

  • Soft Snowfall Field (3): open outdoor snow
  • Frozen Creek Path (3): ice trickle under snow
  • Night Market Steam (3): steam plumes and a quiet winter street
  • Cabin Porch Winter (3): wooden porch creaks, cold wind outside
  • Frosted Window Dusk (3): half-indoor frost hush
  • Snowy Lantern Path (3): distant bells along a lit path

Specs: 48 kHz / 24-bit stereo WAV + OGG Vorbis. Loudness about -18 LUFS integrated (±1 LU), true peak at or below -1 dBTP. Each loop join was crossfade-tuned and measured (RMS jump under 1.5 dB in 50/100 ms windows). Clear file names like soft_snowfall_full_mix_loop.ogg. Works in Godot, Unity, GameMaker, RPG Maker, Unreal and Defold: just set the sound to loop.
