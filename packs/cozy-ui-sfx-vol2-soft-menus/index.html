What is in it

188 soft menu sounds · 11 categories · WAV 48 kHz/24-bit + OGG · Godot / Unity ready

Soft, warm menu cues for cozy, farm and life-sim games. Vol.1 covers general UI; Vol.2 is all about menus and panels, so every screen of your game can open, slide, select and close with the same gentle sound.
