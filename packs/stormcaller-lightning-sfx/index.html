What is in it

Call down the storm. Stormcaller is a sound pack for one element, done properly: lightning magic and the thunderstorm it comes from. Charge a spell, release the bolt, chain it through enemies, raise a storm shield, and let the thunder roll behind it, all from one set of sounds that belong together.

What's inside: 158 sounds, every one as WAV + OGG (316 files)

  • Charge (13): charge_short ×5, charge_long ×4 (2.1-2.4 s build-ups), charge_crackle ×4
  • Cast (14): cast_snap ×5, cast_surge ×5, cast_rune ×4 (tonal, E minor pentatonic)
  • Bolt (14): bolt_fire ×5, bolt_pass ×4 (fly-by with pan), spark_shot ×5
  • Impact (15): zap_hit ×5, shock_impact ×5, strike_ground ×5 (big strike: leader ticks, crack, boom, sky tail)
  • Chain (10): chain_lightning ×5 (3-6 arcs jumping between targets), arc_jump ×5
  • Layered strike (20): 5 big strikes, each as strike_full plus separate charge / release / tail stems
  • Status (10): electrocuted ×5 (stun buzz with spasms), static_discharge ×5 (tiny static snaps)
  • Loops (12): static crackle, shield hum, storm aura, lightning beam (3 seamless 12 s loops each)
  • Shield (13): shield_up ×4, shield_hit ×5, shield_down ×4
  • Thunder (14): thunder_close ×5, thunder_distant ×5, thunder_roll ×4 (~7 s)
  • Storm ambience (3): 60 s seamless storm beds: light rain, heavy storm, arcane storm
  • Spell UI (20): spell select, cooldown ready, mana empty, spell hover (5 each)

Built for gameplay

  • 3-5 variations of every sound, so a spell you cast 200 times doesn't sound copy-pasted
  • Layered strike stems: play the charge while the spell winds up, then fire release + tail the moment the bolt lands (release timings listed in the README)
  • Seamless loops: built sample-periodically (no crossfade bump at the loop point) and tagged with a WAV loop point; hold a charge with a loop, then release
  • Loudness matched across the pack (-18 LUFS one-shots, -16 LUFS big hits, -20 LUFS loops and ambience, -24 LUFS light ticks), true peak ≤ -1 dBTP, no clipping, no silent heads or tails
  • Easy on the ears: high frequencies kept smooth (under 10% of the energy above 8 kHz in every file), so rapid zaps don't get harsh
  • 48 kHz / 24-bit stereo WAV for editing + OGG Vorbis for your engine, same file names in both
  • Every file was measured; the QA report is in the pack

Godot / Unity ready

Use the OGG files directly in Godot, Unity, GameMaker, Unreal, Defold, RPG Maker or Construct. For the _loop files: in Godot 4 turn on Loop in the Import dock; in Unity tick Loop on the AudioSource.
