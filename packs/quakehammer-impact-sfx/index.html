What is in it

Make every hit feel heavy, and make the camera shake sound right. Quakehammer is 165 impact and screen-shake sounds for platformers, action games, boss fights and anything that explodes: soft and hard thumps, ground slams, near and far booms, sub drops, debris, wood and metal crashes, short screen-shake layers, seamless rumble loops and impact stingers. Every family comes in light, medium and heavy, so the sound grows with the hit and the camera shake.

Built around weight, not a random folder of bangs

  • Three force tiers, locked to loudness: every family ships _light (-22 LUFS), _medium (-18) and _heavy (-14). The heavy take is a bigger version of the same design (more body, more low end, longer tail), not a different sound, so a light and a heavy slam still belong together. A bigger hit is a louder file, no mixer work.
  • One call per hit: QuakeSfx.hit("ground_slam", power) maps power 0..1 straight onto light / medium / heavy, the same 0..1 value you already feed your screen shake. QuakeSfx.quake(power) fires ground slam + sub drop + shake layer on the same frame at the same tier; QuakeSfx.boom(power, far) adds the shake under a near or far boom.
  • Layers you can stack: sub_drop as a bass bed under anything, shake_layer as a short sweetener that sits on top of a camera shake, debris and crash_wood / crash_metal for what breaks, impact_stinger for kill, finisher and boss-phase beats.
  • Sustained quakes: 12 seamless rumble loops (8 s, sample-exact, WAV loop points), light to heavy, with rumble_start(power) / rumble_stop() fading them in and out for earthquakes, collapsing levels and boss rumbles.

What's inside: 165 sounds, every one as WAV + OGG (330 files) + Godot 4 and Unity helper scripts

  • Soft thump (15): thump_soft light / medium / heavy ×5
  • Hard thump (15): thump_hard light / medium / heavy ×5
  • Ground slam (15): ground_slam light / medium / heavy ×5
  • Near boom (15): boom_near light / medium / heavy ×5
  • Far boom (12): boom_far light / medium / heavy ×4
  • Sub / bass drop (15): sub_drop light / medium / heavy ×5
  • Debris / rubble (15): debris light / medium / heavy ×5
  • Crash, wood and metal (15): crash_wood light / medium / heavy ×3, crash_metal light / medium / heavy ×2
  • Screen-shake layer (21): shake_layer light / medium / heavy ×7
  • Rumble loop (12): rumble light / medium / heavy ×4 (seamless loops)
  • Impact stinger (15): impact_stinger light / medium / heavy ×5

Made for game feel

  • Snappy: every one-shot starts within 5 ms of the file start (no silent lead-in) and ends with a clean tail; the variations of a sound match within about 0.1 dB, so random variants never jump in volume
  • True peak ≤ -1 dBTP, 0 clipped samples, no DC offset; 48 kHz / 24-bit stereo WAV + OGG Vorbis, same file names in both; every file measured (length, loudness, peak listed in MANIFEST.csv)

Godot 4 + Unity drop-in: copy ogg/ to res://quakehammer/ and add quake_sfx.gd as an Autoload named QuakeSfx, or copy it to Assets/Resources/Quakehammer/ and add the QuakeSfx component in Unity. Then QuakeSfx.play("ground_slam_heavy") / QuakeSfx.Play("ground_slam_heavy") plays a random variant (never the same one twice in a row); plus hit, shake, quake, boom, rumble_start / rumble_stop and play_at / PlayAt for positional sounds. The Godot helper was tested headless in Godot 4.7 (every family loads in all three tiers, every helper call runs); the Unity script builds with 0 errors against a UnityEngine stub (not yet run inside the Unity editor). File names are plain lowercase snake_case, so GameMaker, Unreal, Defold, RPG Maker, Construct or Phaser work too.
