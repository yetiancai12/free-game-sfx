What is in it

192 emotion babble sounds · 8 emotions × 6 voices · WAV 48 kHz/24-bit mono + OGG · Godot / Unity ready

Emotion layer for dialogue boxes. Pair with Chatterbox Voices (Vol.1) or use alone: happy, sad, angry, scared, surprised, tender, tired, nervous — three short syllables and one short phrase per voice × emotion. Code-made babble only (no recorded human voices, no voice cloning). File names use emo_ / phrase_ so they never collide with Vol.1 voice_ / line_ files.

What's inside (192)

  • Emotion syllables (144) — 3 takes per voice × emotion
  • Emotion phrases (48) — 1 short babble per voice × emotion

Six base voices (one from each Vol.1 family): chip_square, creature_slime, inst_marimba, tech_robot, type_bubble, villager_calm.

Mixed to sit with Vol.1: syllables about −24 LUFS; phrases about −18 LUFS (typing-style phrases stay −24); true peak ≤ −1 dBTP. Every file's length, loudness and peak is in MANIFEST.csv. Engine examples: say(text, emotion) for Godot 4 and Unity.

Files: wav/ and ogg/ with identical names and folders, README, LICENSE, MANIFEST, engine_examples.
